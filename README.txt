SETSWANA ROBOTICS - WEB EVALUATION VERSION

1. Open this folder in VS Code.
2. Open a terminal in the folder.
3. Run: py -m pip install -r requirements.txt
4. Run: py -m streamlit run streamlit_app.py
5. Test first as a teacher, then as a learner.

Use test/participant codes rather than real names where appropriate.
This web version is for remote evaluation. The existing Tkinter desktop application remains the main offline prototype.
