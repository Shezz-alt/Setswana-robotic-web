SETSWANA ROBOTICS LEARNING SYSTEM

Designing and Developing a Setswana-Based Robotic System for Rural Primary Schools in Mahikeng.

The Setswana Robotics Learning System is designed to support teachers and learners in learning introductory robotics and coding concepts through Setswana.

The system provides:

• Teacher and learner access
• Setswana-based robotics lessons
• Interactive robot-parts learning
• Robot programming and simulation
• Robotics learning activities and challenges
• Learner progress tracking
• Teacher monitoring of learner progress

The system introduces learners to robotics concepts, robot movement, command sequencing, algorithms and programming through an interactive learning environment.

SYSTEM FILES

streamlit_app.py
Main application interface and system functions.

web_database.py
Manages teacher and learner accounts, lesson progress and activity progress.

requirements.txt
Contains the software requirements needed to run the system.

RUNNING THE SYSTEM

1. Open the project folder in Visual Studio Code.
2. Open a terminal in the project folder.
3. Install the required packages:

py -m pip install -r requirements.txt

4. Start the system:

py -m streamlit run streamlit_app.py
